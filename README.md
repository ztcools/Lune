## 🚀 本地启动

### 环境要求

Java 17 · Maven 3.8+ · Node.js 18+ · MySQL 8.0 · Redis

### 1. 初始化数据库

```bash
mysql -u root -p < lune-server/lune-web/src/main/resources/sql/lune.sql
```

默认管理员账号：`admin` / `admin123`

### 2. 启动后端

```bash
cd lune-server/lune-web
mvn spring-boot:run
# → http://localhost:8081
```

### 3. 启动前端

```bash
cd lune-ui
npm install
npm run dev
# → http://localhost:5173
```
